      Tree ring data from the Niwot Ridge subalpine zone, 2017 - 2018.
      
         Rachel K Chai
         rachel.chai@colorado.edu
      
      2024-05-24
      English
      
         
    Tree cores were collected across a range of diverse stand types and
    topographic positions in 2017 and 2018 to examine changes in tree
    growth as a response to changing climate in the subalpine forest of
    the Colorado Front Range, USA. Tree cores were collected for all
    present species in the subalpine zones; Engelmann spruce (Picea
    engelmannii), subalpine fir (Abies lasiocarpa), lodgepole pine
    (Pinus contorta) and limber pine (Pinus flexilis). We extracted core
    from ~180 trees from 3 large permanent plots across a range of
    species and sizes classes within each plot. The cores were then
    processed using WinDENDRO software. This dataset includes field data
    taken on each tree from which a core was extracted, the original
    WinDENDRO files for each coree.g. bark thickness, height, etc.), 2)
    MRS4 .txt fil output from WinDENDRO, 3) MRS5 .txt fil output from
    WinDENDRO, 4) MRS7.txt fil output from WinDENDRO, The WinDENDRO,
    outputs will be used to reconstruct a time series of radial growth
    for each tree in each plot to examine whether the topoclimatic
    position affects tree growth (by species and stand types) and
    whether tree growth has changed with warming temperatures.

    Tree cores were taken from three plots (MRS4, MRS5, and MRS7) in the
    subalpine zone of the Colorado Front Range, USA with the intent to
    capture variation between stand types exhibited in the subalpine
    zone. MRS4 is a mesic site, MRS5 is a hydric site, and MRS7 is a
    xeric site. In each plot ~60 tree cores were taken from all tree
    species in each plots and across all size classes within each
    species. In MRS4 and MRS7, four subalpine tree species can be found;
    Engelmann spruce (Picea engelmannii), subalpine fir (Abies
    lasiocarpa), lodgepole pine (Pinus contorta) and limber pine (Pinus
    flexilis). In MRS5, a composition equilibrium old-growth stand, only
    two of the four species can be found; Engelmann spruce and subalpine
    fir. Cores were taken at DBH (diameter at breast height). Two cores
    were taken from each tree, one core parallel to the slope and one
    core perpendicular to the slope. From each tree that cores were
    extracted, we reported species, DBH (diameter at breast height in
    cm), height (in meters using a laser rangefinder), crown base (in
    meters using a laser rangefinder), and bark thickness (in cm using a
    bark gauge). Following standard protocol, the cores were then dried,
    mounted, and sanded. Each core was then scanned into WinDENDRO where
    annual tree-ring measurements were computed to produce ring-width
    series’ for each tree in each plot. We then created cross-dated and
    converted chronologies to a Tucson (decadal) format file (.rwl
    files). Some files in the original WinDENDRO output we were not able
    to cross-date because they either had different growth patterns or
    contained lot of missing rings or measurement errors. These
    individuals are not included in the Tucson (.rwl) files. We found
    that many of the ring width series do not correlate particularly
    well. This may be due to either errors in measurement and/or
    differential growth responses of individual trees within the plots.
    In a few cases, the species code in the windendro file does not
    match with those in the field (treecore) file due to a labeling
    error in the lab. In these cases (e.g. MRS4 tree# 116) please refer
    to the species identity in the field (tree core) spreadsheet.
  
               
    Additional ring width data from the same sites at Niwot Ridge may be
    found in the NOAA National Centers for Environmental Information
    (NCEI), under the World Data Service (WDS) for Paleoclimatology,
    under the following dataset identifiers: doi:10.25921/qbrd-0k44;
    doi:10.25921/mvac-ww18; doi:10.25921/shv2-1010.
