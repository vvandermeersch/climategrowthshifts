Lizzie,

I have attached the data for ponderosa pine for the Soaproot Saddle site
that we were focusing on and the COFECHA output characterizing the
chronology. Some of the data are those my first grad student (Rachel
Keen) and I collected in spring of 2017 (last ring formed and reported
is 2016 unless the tree died earlier and the core was degraded due to
decay). These data labels for each core start with "SS", the next number
is the plot (1-13), then a dash and then the tree number. There were
multiple cores extracted per tree corresponding to the letter code at
the end of each data label.

Added to these data are additional ponderosa pine data collected by Ryan
Ferrell across the same area a couple years earlier. These data labels
started with "SRA". Ryan was a co-author on a previous paper about which
trees lived or died -- led by Rachel Keen. Ryan's cores were from his
unpublished MS degree and have soil depth data at each site (metadata
not included here). I never got around to re-analyzing those patterns.

If you need the ring-width data from the other sites we reported on from
further away I could probably dig those up too - let me know.

Steve
