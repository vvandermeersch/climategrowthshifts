There are mostly small trees, which have just reached DBH threshold of 5 cm—but not only.
Coincidentally, trees with missing IDs are the only ones where columns related to canopy (Canopy_class, Crown_ratio, Azimuth…) are not `NA.

Let’s do a quick check on unidentified trees with DBH > 20cm, just to start (21 trees).

bigtrees_noid <- mtr_2024_sub[is.na(mtr_2024_sub$TreeID) & mtr_2024_sub$Dbh > 20, ]

Some of these trees are fused, or shared a common base, with another tree—which could explain why they don’t have an ID?
Let’s look at the others.

bigtrees_noid_noshare <- bigtrees_noid[!grepl("Fused|Shares", paste(bigtrees_noid$Comment_1, bigtrees_noid$Comment_2, bigtrees_noid$Comment_3, bigtrees_noid$Comment_4)),]

TREEID variable is made with STANDID and PLOTNUMBER.
For example, a tree on stand AR19 and plot 5 would have an ID beginning by AR190005.
It might help us to find some missing trees?

wheretolook <- paste0(bigtrees_noid_noshare$Stand, ifelse(bigtrees_noid_noshare$Plot < 10, paste0("000", bigtrees_noid_noshare$Plot), paste0("00", bigtrees_noid_noshare$Plot)))

for(i in 1:length(wheretolook)){
  
  dbh_threshold <- bigtrees_noid_noshare[i, "Dbh"]-2  # -2, not to be too restrictive
  sp <- bigtrees_noid_noshare[i, "Species"]
  potential_trees <- unique(mtr_data[grepl(wheretolook[i], mtr_data$TREEID) & 
                                       mtr_data$YEAR %in% c(2017) & 
                                       mtr_data$DBH < dbh_threshold &
                                       mtr_data$SPECIES %in% sp, ])
  
  already_present <- mtr_2024_sub[mtr_2024_sub$TreeID %in% na.omit(potential_trees$TREEID), ]
  
  cat(paste0(nrow(potential_trees)-nrow(already_present), " "))
  
}
0 0 0 0 0 0 0 0 0

We get only zeros, meaning that all potential trees in the PSP dataset (before 2024) that could correspond to trees with missing IDs are already in the 2024 dataset! We could try to do the same thing, with trees with DBH between 10 and 20 cm.
