\f0\fs24 \cf0 README for Dryad Repository:\
Data for 
\f1 Local range boundaries versus large-scale tradeoffs: Climatic and competitive constraints on tree growth\
Leander DL Anderegg & Janneke HilleRisLambers\
2019\
\
for additional information and ancillary data (calculated Basal Area Increment data, climate time series for sampled sites from multiple sources, etc), please contact Leander DL Anderegg at leanderegg@gmail.com\
\
This repository contains 3 .zip files.\
\
1) 	SI_Data_and_code.zip - simplified example data to demonstrate manuscript analysis (using Abies lasiocarpa from Colorado transect) and associated example R code. This is a copy of the SI Data and Code files provided with manuscript outside of Ecology Letter\'92s paywall.\
\
2) 	Tree_Info_BAI_012118.zip - focal tree information (size, competitive environment, regeneration densities within 5m, and 10yr Basal Area Increment summaries from 2003-2012) for all focal trees and all nine species replicates. Each species replicate has its own .csv file, and metadata can be found in the \'93_Metadata_XX.csv\'94 file.\
\
3) 	Raw_Ring_Widths_012118.zip - raw ring width data for all focal trees and all nine species replicates. Each species replicate has its own .csv file, and metadata can be found in the \'93_Metadata_XX.csv\'94 file.}
