This folder contains the model files and analysis scripts of the $\delta$ model. The $\delta$ model is in the stan fodler. 
Below are the analysis scripts:
- data_sim.R -> fake data simulation
- confronting_with_real_data.R -> fitting the model on real data (2008 mountrainier)
- visulization.Rmd -> making plots about posterior distributions and posterior predictive check.
